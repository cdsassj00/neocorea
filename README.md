# NEO COREA 동물병원 — 3D 스크롤 랜딩 페이지

평택 최초 한방재활 특화 **네오코리아동물병원**을 위한 스크롤 인터랙티브 홈페이지입니다.
외부 라이브러리·CDN 없이 **단일 `index.html`**로 동작하여, 더블클릭으로 바로 열리고 망분리 환경 시연에도 그대로 쓸 수 있습니다.

## 구성

```
index.html      # 페이지 전체 (HTML + CSS + JS 한 파일)
assets/
  hero.jpg      # 히어로 (고양이+토이푸들)
  g1~g6.jpg     # 3D 갤러리 커버플로우
  care.jpg      # 병원소개 밴드
```

## 스크롤 인터랙션

| 구간 | 효과 |
|------|------|
| 히어로 | 마우스 방향으로 이미지 3D 틸트, 떠다니는 칩 |
| 진료안내(오르빗) | **스크롤에 따라 7개 진료과목이 중앙 이미지 주위로 궤도를 돌며 퍼짐** |
| 갤러리 | **3D 커버플로우** — 드래그/화살표로 카드가 원근 회전 |
| 진료과목 | 카드 3D 호버 틸트 |
| 통계 | 스크롤 진입 시 숫자 카운트업 |

원리는 하나입니다 — `스크롤 진행률(0~1)` 하나로 회전·위치·투명도를 매 프레임 계산합니다. 애니메이션 재생이 아니라 **스크롤바 = 재생 헤드**.

## 수정하는 법

- **병원 정보/연락처**: `index.html` 하단 `<script>`의 `DEPTS`, `GALLERY` 배열과 각 섹션 텍스트를 직접 편집
- **이미지 교체**: `assets/`의 파일을 같은 이름으로 덮어쓰기 (히어로 16:9, 갤러리 3:4 권장)
- **브랜드 컬러**: `:root`의 `--g1/--g2/--g3`(레드→퍼플→블루 로고 그라데이션)

이미지는 다크 스튜디오 톤(따뜻한 브라운 배경 + 크림색 반려동물 + 시네마틱 조명)으로 통일되어 있어, 슬라이드·SNS 소재로도 그대로 활용할 수 있습니다.
